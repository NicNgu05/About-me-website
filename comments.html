Webpage Structure

The framework for this website was split into 4 main parts, each separated by its own div element:
  • Title
  • Header
  • Main
  • Footer
Structuring the page this way kept the HTML organised and made styling more manageable, since each div could be targeted individually in the CSS file without any of the styles bleeding into other sections of the page.

Title

This is just the title of the website. This title was done using h1 and was placed in the div .title.

Header

All content within the this div is defined under the .header class in the CSS file. This div the navigation bar with its respective hyperlink of each button.

main

This is where the main content sits, which also includes the title of the page. All content within this div is defined under the .main class in the CSS file. This section holds the primary content of each page, keeping it visually separated from the rest of the divs so the layout stays clear and easy to navigate if content is updated later on.

Footer

The footer div was kept very simple. It contained a supplementary navigation bar so the user had a quicker alternative to change pages, along with the name of the subject. The way the information was split and placed on both sides of the page was through the use of justify-content: space-between which allowed for the content and second navigation bar to be seperated adding a more minimialist look.

Aesthetic

With this website, a minimalistic approach was taken to keep it clean, as adding too much would ruin the aesthetic and usability of the site. A blurred background using .background::before added a nice touch without overdoing it. When it came to font colour and style, Segoe UI was used for the body text, and Times New Roman for the page title. This was chosen because the italic look of the title added some contrast to the minimalistic design and gave it a bit of 'pop'.

In terms of interactions, the navigation bar gives the user a physical cue when hovered over, through a transforming underline. This was implemented by having the underline already in place, but invisible, using scaleX(0). Once the user hovers over a button, the underline animates in using scaleX(1), creating a smooth transition effect For the past section, instead of the tradition list for the past computing journey. A vertical timeline was adopted with alternating tree branches. This was done using nth-child(odd) and nth-child(even) selectors which branched off a center vertical stems with connecters connecting each branch to the stem. This gave the section some personality and while still keeping the information to follow due to it already being in chronology order in a visually engaging way.

Accessibilty

Screen Reader & Structure

As noted above this, the structure was kept simple and minimalistic so that is was easy to navigate with any random clutter like a casino room. This way everything was given to the user without them feeling confused with a clear chronology order structure. Not only that, all images within this website have alt text so that when images are turned off, the user can visualise what is being shown through the description. The implemention of the correct headers allowed that when customed css was turned off, title, sub-headings and body of text could be distinguished from one another. Any links that were implemented as well would turn bold when hovered over and the navigation bar had animation that would indicate if it was being hovered over.

Font Size

When it came to font size, a default font size of 18px was set however, everything within the website scales by % so that if the page was zoomed out or in it would still be readable

Font Selection

for font selection, a clean font needed to be selected so that nothing in the website would be too difficult to read so Segoe UI was used for the body text. The implemention of Times New Roman for the page title was also selected because the italic look of the title added some contrast to the minimalistic design and gave it a bit of 'pop'

Colour Selection

For the background, the nice dark green tone background was selected, with a aliceblue text. This was tested on a contrast checker (webAIM) which passed with a contrast ratio of 11.29:1.
